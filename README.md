# Semiconductor School RISE Fellowship – Cohort 2

## RV32I Single-Cycle Processor Design Using Verilog HDL

Welcome to my project repository for the **Semiconductor School RISE Fellowship – Cohort 2**, undertaken as part of the RISC-V for Indian Semiconductor Education initiative.

This repository showcases my fellowship certificates and hands-on work involving the design, implementation, debugging, and simulation of a **32-bit RISC-V (RV32I) Single-Cycle Processor** using Verilog HDL.

## About the Project

The project focuses on understanding and implementing the internal architecture of a RISC-V processor.

The processor follows a single-cycle architecture, integrating the major hardware components required for instruction execution, including the ALU, register file, control unit, instruction memory, and data memory.

## Technologies Used

- Verilog HDL
- AMD Xilinx Vivado
- XSim Simulator
- RISC-V RV32I Instruction Set Architecture
